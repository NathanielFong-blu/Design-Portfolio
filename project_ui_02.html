PROJECT 02

Canada Type - Leather
Web Typeface Documentation

UI DESIGN | WEB DEV

Project Aim Research Draft Making User Research Final Result

PROJECT AIM

A webpage project with HTML and CSS, dedicated to showcasing and documenting the Canada Type - Leather 20 font created by Patrick Griffin. Designed with user-friendly, engaging and intuitive interface in mind.





DESIGN & UI RESEARCH

Since Leather is a black letter inspired typeface, I searched through Old English manuscripts for inspiration. I also researched into other typeface webpage that has a strong minimalist and sleek design, since I think it will contrast complex tpyeface such as Leather.





DRAFT MAKING

Based on my research, I decided to experiment with both styles: manuscripts and strong minimalist.














USER RESEARCH & WIREFRAMING

I conducted a small sample sized user research.
- manuscripts seems flat and outdated
- manuscripts does not fit Leather modern interpretation
- webpage feels flat and lack user interactivity

As for the strong minimalist design:
- strong and last an impression
- more related to Leather's core design

So I decided to redo the design after an analysis of GT Pantheon, another typeface website I took great inspiration from.

Through the user research, I learnt:
- simple interface, only scrolling and button clicking to interact with page
- simple inforgraphics to display typography
- grid structure for glyphs

Based on these I redesigned my webpage to use a simple structure, and interactive ui elements to boost engagements.





FINAL RESULT

I then coded the Canada Type - Leather Documentation Webpage
